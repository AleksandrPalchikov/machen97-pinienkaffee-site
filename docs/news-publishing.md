# Новости и статьи Pinienkaffee

Адрес раздела: https://machen97.com/aktuelles/

Публикации можно добавлять через чат: пришлите текст, заголовок, желаемую дату и при необходимости изображение. Ассистент подготовит страницу, проверит её и опубликует по вашему поручению. Отдельной административной панели в этой версии нет.

## Для разработчика или следующего ассистента

- Источники: `content/articles/*.json`.
- Сборка без сторонних библиотек: `python3 scripts/build-news.py` из корня репозитория.
- Сборка создаёт `aktuelles/index.html`, отдельные `aktuelles/<slug>/index.html`, `aktuelles/feed.xml` и `sitemap-aktuelles.xml`.
- `robots.txt` содержит адрес дополнительного sitemap; исходный sitemap сайта не заменён.
- GitHub Actions запускает сборку перед деплоем. Сгенерированные страницы также коммитятся, чтобы локальный просмотр работал сразу.
- Главная страница `index.html` не участвует в сборке. Не добавляйте на неё ссылки и не меняйте её без отдельного поручения пользователя.
- Служебные каталоги `content`, `scripts`, `docs`, архивы и настройки исключены из публичной загрузки через `.assetsignore`.

## Формат публикации

Используйте существующую публикацию как образец. Обязательные поля:

- `slug`: постоянный адрес, латинские строчные буквы, цифры и дефисы.
- `title`, `description`: заголовок и краткое описание.
- `category`: `news` для новости или `article` для статьи.
- `published`, `modified`: время в ISO 8601 с часовым поясом; не меняйте дату первоначальной публикации при редактировании.
- `status`: `published` для публикации, `draft` для черновика. Будущие публикации не выводятся до наступления их даты; автоматического запуска в эту дату нет, нужен повторный деплой.
- `image`: существующий файл в `/images/`; `image_alt`: содержательное описание изображения.
- `intro`: список вводных абзацев.
- `sections`: список разделов с `heading` и `paragraphs`; при необходимости `link` с `label` и внутренним `href`.

Не добавляйте неподтверждённые новости, даты, отзывы, сертификаты или медицинские обещания. Разметка `NewsArticle`/`BlogPosting` должна соответствовать видимому тексту, дате и автору. Автор и издатель — M97 Factory / Machen97 UG; для другого автора потребуется расширить источник и видимую подпись.

После изменения выполнить сборку, проверить страницу в браузере на компьютере и телефоне, убедиться в доступности её канонического адреса, изображений, ссылок и JSON-LD. Коммитить только файлы задачи, не включать чужие изменения или `.DS_Store`. После push дождаться успешного GitHub Actions и проверить страницы на основном домене.

## Поиск и ИИ

Публикации содержат полный текст в HTML, канонический адрес, описание, даты, автора, изображение, JSON-LD статьи и хлебные крошки. В sitemap включены только опубликованные страницы; страница благодарности не включается. RSS обновляется при сборке.

Индексация и цитирование не гарантируются технической настройкой. Проверяйте URL и sitemap в Google Search Console. Правило `User-agent: * / Allow: /` в текущем `robots.txt` разрешает обход, в том числе поисковым ботам; отдельные настройки защиты Cloudflare могут влиять на доступ независимо от `robots.txt`.
